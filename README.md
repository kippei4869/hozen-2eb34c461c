# 機械保全技能士1級 学科トレーナー（PWA）

2020〜2025年度（第2回）機械系保全作業 1級 学科試験の過去問 299問を収録した、
オフラインで動く学習用サイトです。WES1級のサイトと同じ構成にしてあります。

## 収録内容
- 全299問（○×150問／四択149問）。2024年度 問40は「問題不成立のため削除」なので除外
- 全問に解説つき。図表問題28問は試験問題PDFの図をそのまま埋め込み
- 正解はすべて公式正解表と機械照合済み

## 置き方（GitHub Pages）

WES1級のときと同じ手順です。

1. GitHub で新しいリポジトリを作る
   - 名前の例：`hozen-2eb34c461c`（推測されにくい名前にしておくと実質的に非公開になります）
   - Public、README なしで作成
2. このフォルダの中身を**すべて**リポジトリ直下にアップロード
   （`index.html` `sw.js` `manifest.webmanifest` `icon-*.png` `robots.txt` `.nojekyll`）
   - `.nojekyll` は隠しファイルなので、ドラッグ＆ドロップで出てこない場合は
     GitHub の「Add file → Create new file」でファイル名に `.nojekyll` と入力して空のまま Commit
3. Settings → Pages → Source を **Deploy from a branch**、`main` / `(root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/hozen-2eb34c461c/` で開けます

既存の WES 用リポジトリに相乗りさせる場合は、リポジトリ内に `hozen/` フォルダを作って
中身を入れれば `https://<ユーザー名>.github.io/<既存リポジトリ>/hozen/` で動きます。
パスはすべて相対指定にしてあるので、サブフォルダでもそのまま動作します。

## iPhone での使い方
Safari で開く → 共有ボタン → 「ホーム画面に追加」。
以後はアイコンから全画面で起動し、**圏外でも動きます**（初回だけ通信が必要）。

## 記録について
正誤の記録は端末のブラウザ内（localStorage）に保存されます。サーバーには何も送りません。
ホーム画面「これまでの記録」の **記録を書き出す／読み込む** でJSONとしてバックアップでき、
機種変更やブラウザのデータ削除に備えられます。

## 更新のしかた
問題や解説を直したら `index.html` を差し替え、あわせて `sw.js` の
`const CACHE = 'kikaihozen1-v1'` の **v1 を v2** のように上げてください。
番号を上げないと、端末に残った古いキャッシュが表示され続けます。
